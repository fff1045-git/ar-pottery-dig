# AR 도자기 발굴 — 설계

작성 2026-10-20. GPS 수집 게임(별도 저장소)의 지도·GPS·시뮬레이터 코드를 가져와 만든 별개의 게임이다.

## 한 줄 요약

위성 지도에서 금속탐지기 신호를 따라 숨은 발굴 지점을 찾고, 가까이 가면 카메라 화면 속 땅의 흙을 손가락으로 문질러 걷어내 도자기 파편을 꺼낸다. 파편 4조각을 모으면 도자기가 복원된다.

## 확정한 것 (사용자와 정함)

| 항목 | 결정 |
|---|---|
| 지점 찾기 | 지도에는 "이 근처 어딘가"를 뜻하는 흐린 원(반경 60m)만 보인다. 원 안에서는 탐지기 신호(막대·삐 소리·진동)가 가까울수록 강해진다. |
| 파기 | AR 화면에서 손가락으로 문지르면 흙이 지워진다. 흙은 2~4겹이고 깊을수록 단단하다(같은 자리를 더 오래 문질러야 한다). 파편 영역의 70%가 드러나면 획득한다. 깨짐 패널티는 없다. |
| 복원 | 조각 지정형. 도자기마다 입전·어깨·몸통·굽 4조각. 중복 조각은 "고운 흙"으로 바뀌고, 고운 흙으로 모자란 조각을 교환할 수 있다. |
| 지점 갱신 | 하루 단위. 한국 시간 자정에 전국 배치가 바뀐다. 한 번 판 지점은 그날 다시 나오지 않는다. (사용자 확인 전 기본값으로 정함) |

## 그대로 이어받는 것

- 대한민국 전역, 격자 셀 시드 기반 결정적 배치, 영역 밖이면 지점 없음 + 안내.
- 시작 위치: `?at` → 현재 위치 → 마지막 위치 → 사용자가 검색이나 지도 클릭으로 고름. 고정 기본 좌표는 없다.
- 1인용, 서버 없음, localStorage 저장. 지도 사용량 최적화는 하지 않는다.
- 지도: 카카오 HYBRID(스카이뷰), 실패하면 Leaflet 폴백. 시뮬레이터(WASD, 지도 클릭으로 걷기·순간이동, 장소 검색).
- 개발 서버 포트는 5174 고정(기존 게임 5173과 동시 실행). 카카오 콘솔 JavaScript SDK 도메인에 `http://localhost:5174` 추가 필요.

## 게임 규칙 (숫자)

- 격자 셀 150m, 셀마다 지점 0~2곳(균등). 하루 창 = `floor((now + 9h) / 24h)`.
- 지점마다 정해지는 것: 위치, 파편(도자기 + 조각), 흙 겹 수(흔함 2 · 조금 드묾 3 · 희귀 3 · 전설 4), 탐색 원 중심(실제 위치에서 0~35m 떨어진 결정적 오프셋, 원 반경 60m라 실제 위치는 항상 원 안).
- 도자기는 희귀도 가중치로 뽑고, 조각 4개는 균등.
- 발굴 가능 거리 20m, GPS 정확도가 50m보다 나쁘면 발굴 불가.
- 탐지기 신호(가장 가까운 안 판 지점 기준): 60m 밖 0, 그 안에서 거리에 따라 1~5단계, 20m 안이면 5단계 + "발굴하기" 버튼.
- 고운 흙: 중복 조각을 얻으면 흔함 1 · 조금 드묾 2 · 희귀 4 · 전설 10. 교환 비용은 그 5배(흔함 5 · 조금 드묾 10 · 희귀 20 · 전설 50).
- 복원 보상: 도자기가 처음 완성되면 고운 흙 보너스(희귀도별 흔함 3 · 조금 드묾 6 · 희귀 12 · 전설 30)와 도감에 완성 그림.

| ID | 이름 | 희귀도 | 가중치 |
|---|---|---|---|

| moonjar | 백자 둥근 항아리 | 조금 드묾 | 18 |
| bluewhite | 청화백자 풀꽃무늬 병 | 조금 드묾 | 12 |

## 화면

1. **지도 화면**: 내 위치, 흐린 탐색 원들(판 지점은 사라짐), 아래쪽 탐지기 패널(신호 막대 5칸 + 상태 문구). 시뮬레이터 모드에서는 화면에서, 실제 GPS 모드에서는 소리·진동도 낸다(소리는 켜고 끌 수 있음). 20m 안이면 "⛏️ 발굴하기" 버튼.
2. **AR 발굴 화면** (전체 화면 오버레이):
   - 배경: 후면 카메라(`getUserMedia({ video: { facingMode: 'environment' } })`). 권한이 없거나 카메라가 없으면 흙바닥 그림 배경.
   - 기울기: `deviceorientation`의 beta로 휴대폰이 아래를 향할수록 발굴 판이 화면 아래에서 올라온다(beta 60° 이하면 다 보임). 센서가 없거나(PC) 권한이 없으면 처음부터 다 보인다. iOS는 시작 버튼을 누를 때 권한을 요청한다.
   - 발굴 판: 원근감 있게 눕힌 타원형 흙더미. 맨 아래 파편 그림, 그 위에 흙 겹 캔버스. 문지르면 맨 위에 남은 겹부터 지워진다.
   - 겹이 처음 뚫릴 때 짧은 진동. 70% 드러나면 파편이 튀어 오르며 획득 카드("청자 매병 · 어깨 조각 · 새 조각!" 또는 "중복 → 고운 흙 +4").
   - 나가기 버튼. 중간에 나가면 진행은 버린다(그 지점은 그대로 남음).
3. **도감 화면** (시트): 도자기 6종 카드. 조각 4칸(가진 조각만 보임), 완성되면 전체 그림. 모자란 조각 옆 "교환(고운 흙 N)" 버튼. 위에 고운 흙 보유량과 복원 수.

## 구조

| 파일 | 하는 일 | 의존 |
|---|---|---|
| `core/*` | 좌표·한국 영역·시드 난수 (그대로) | 없음 |
| `game/grid.ts` | 셀 계산(기존 spawner의 격자 부분) | core |
| `game/pottery.ts` | 도자기·조각 카탈로그, 희귀도, 흙 값 | 없음 |
| `game/sites.ts` | 하루 창, 결정적 발굴 지점 | grid, pottery |
| `game/detector.ts` | 거리 → 신호 단계 | 없음 |
| `game/collection.ts` | 조각 추가·중복→흙·교환·복원 판정 (SaveData를 다루는 순수 함수) | pottery |
| `game/excavation.ts` | 발굴 판 격자: 칸마다 겹별 남은 단단함, 문지르기 적용, 진행률 | 없음 |
| `game/storage.ts` | 저장 형식 v1과 localStorage | 없음 |
| `game/GameState.ts` | 위치·지점·발굴 확정(거리 재검증)·도감 | 위 전부 |
| `ar/camera.ts`, `ar/tilt.ts` | 카메라 스트림, 기울기 구독 | 브라우저 |
| `ar/DigScreen.ts` | AR 발굴 화면 DOM·캔버스 그리기·입력 | excavation, camera, tilt |
| `app/hud.ts`, `app/dex.ts`, `app/detectorUi.ts` | 지도 위 UI, 도감, 탐지기 패널·소리 | game |
| `map/*`, `gps/*` | 그대로 | |

발굴 확정은 `GameState.dig(siteId, now)`가 오늘 지점을 다시 계산하고 거리·정확도를 확인한 뒤에만 기록한다. AR 화면은 "다 팠다"만 알리고 보상은 GameState가 정한다.

## 오류·예외

- 카메라 거부·없음·비보안 출처(http 휴대폰): 흙바닥 그림 배경으로 계속하고 작은 안내를 띄운다.
- 발굴 중 지점에서 멀어짐(실제 GPS): 확정 때 거리를 다시 보고, 멀면 "지점에서 너무 멀어졌어요"로 실패, 지점은 남는다.
- 자정이 지나 지점이 사라짐: 확정 때 "오늘 지점이 바뀌었어요".
- 저장 실패: 무시하고 계속(기존과 같음).

## 테스트

- 단위: 하루 창 경계(KST 자정), 지점 결정성·셀 안 위치·탐색 원이 실제 위치를 포함, 탐지기 단계 경계, 발굴 격자(단단함, 겹 순서, 진행률), 도감(새 조각/중복→흙/교환/복원 보너스 1회), GameState 발굴 재검증, 저장 왕복.
- 브라우저: 시뮬레이터로 지점까지 이동 → 발굴 화면(카메라 없는 대체 배경) → 문질러 획득 → 도감 → 새로고침 후 유지.
- 실기기(카메라·자이로·진동)는 HTTPS나 APK가 필요해 별도로 확인한다.

## 범위 밖

- 바다·건물 안 등 갈 수 없는 곳 걸러내기, 서버·랭킹, iOS 빌드.
- 실제 평면 인식(WebXR AR). 이번엔 카메라 영상 위에 2D로 겹친다.
