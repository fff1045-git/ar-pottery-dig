# AR 도자기 발굴

실제 장소를 비추는 카메라 화면 속 땅에서 도자기 파편을 발굴하는 위치 기반 보물찾기 게임입니다.

1. 위성 지도(카카오 스카이뷰)에 노란 원이 보입니다. 그 원 안 어딘가에 파편이 묻혀 있습니다.
2. 아래쪽 금속탐지기의 신호 막대와 삐 소리(휴대폰은 진동도)가 가까울수록 강해집니다.
3. 20m 안에 들어가면 **⛏️ 발굴하기** 버튼이 뜹니다. 카메라 화면 위에 흙더미가 나타나고, 손가락으로 문지르면 흙이 한 겹씩 걷혀 파편이 드러납니다.
4. 도자기마다 입전·어깨·몸통·굽 4조각이 있고, 4조각을 다 모으면 복원됩니다. 중복 조각은 "고운 흙"이 되고, 고운 흙으로 모자란 조각을 바꿀 수 있습니다.

GPS 수집 게임(별도 저장소)의 지도·GPS·시뮬레이터 코드를 바탕으로 만든 별개의 게임입니다. 설계는 [docs/superpowers/specs/2026-10-20-ar-pottery-dig-design.md](docs/superpowers/specs/2026-10-20-ar-pottery-dig-design.md)에 있습니다.

- 지도: 카카오맵 스카이뷰(위성 + 도로·지명). 키가 없거나 불러오지 못하면 개발용 위성 타일(Esri)로 대신 표시합니다.
- 위치: 휴대폰은 실제 GPS, PC에서는 가짜 위치 시뮬레이터.
- 저장: 브라우저(localStorage)에만 저장합니다. 서버는 없습니다.

## 실행

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 <http://localhost:5174> 을 엽니다. 포트는 **5174로 고정**되어 있어 기존 GPS 수집 게임(5173)과 동시에 띄울 수 있습니다. 5174가 이미 쓰이고 있으면 실행되지 않습니다.

localhost에서 열면 **시뮬레이터 모드**로 시작합니다. 시작 위치는 다음 순서로 정합니다. 정해 둔 기본 좌표는 없습니다.

1. `?at=위도,경도` (테스트용)
2. 현재 위치: 브라우저 위치 권한을 허용하면 PC에서도 Wi-Fi·IP 기준으로 대략 잡힙니다.
3. 마지막으로 플레이한 위치(브라우저에 저장됨)
4. 모두 없으면 전국 지도가 뜹니다. 위 검색창에서 장소를 찾거나 지도를 눌러 시작 위치를 고르세요.

| 조작 | 동작 |
|---|---|
| W A S D / 방향키 | 걷기 (초속 4m), Shift를 누르면 3배 |
| 지도 빈 곳 누르기 | 300m 안이면 걸어가고, 더 멀면 순간이동 |
| 검색창 (카카오 지도에서만) | 장소·주소로 순간이동. 실제 GPS 모드에서는 지도만 옮김 |
| 🔊 / 🔇 | 탐지기 소리 켜기·끄기 (기기에 기억) |
| ⛏️ 발굴하기 | 지점 20m 안에서만 보임. 발굴 화면 열기 |
| 🏺 | 도감. 조각·고운 흙·교환·진행도 초기화 |
| 📍 내 위치 / 🛣️ 로드뷰 | 카메라를 내 위치에 고정 / 카카오 로드뷰 |

| URL 파라미터 | 의미 |
|---|---|
| `?sim=0` / `?sim=1` | 실제 GPS / 시뮬레이터로 강제 |
| `?map=leaflet` | 카카오 대신 개발용 지도 |
| `?tiles=osm` | 개발용 지도를 OpenStreetMap 일반 지도로 |
| `?at=37.5663,126.9779` | 시작 위치 강제 (테스트용) |

## 카카오맵 키

기존 GPS 수집 게임과 같은 카카오 앱의 JavaScript 키를 그대로 씁니다. `.env.example`을 `.env.local`로 복사하고 `VITE_KAKAO_JS_KEY`를 넣으세요. `.env.local`은 git에 올라가지 않습니다.

카카오 디벨로퍼스 → 내 애플리케이션 → 플랫폼 → Web → 사이트 도메인에 **`http://localhost:5174`**(개발 서버)와 **`https://localhost`**(앱 WebView)가 등록돼 있습니다(2026-10-21). 휴대폰 테스트용 HTTPS 주소를 쓸 때만 같은 곳에 추가하면 됩니다.

키를 못 불러오면 화면 위쪽에 이유가 뜨고 Esri 위성 타일(개발·시연용)로 대신 그립니다.

## 휴대폰에서 해 보기

브라우저는 **HTTPS**(또는 localhost)에서만 위치와 **카메라**를 줍니다. PC의 `http://192.168.x.x:5174`로 접속하면 GPS·카메라가 둘 다 막힙니다(카메라가 없으면 흙바닥 그림으로 계속 진행됩니다).

- 터널: `cloudflared tunnel --url http://localhost:5174` → 나온 `https://…trycloudflare.com` 주소를 카카오 사이트 도메인에 추가 → 휴대폰에서 `?sim=0`을 붙여 열기.
- 또는 `npm run build`로 만든 `dist/`를 정적 호스팅에 올리고 그 HTTPS 주소를 등록.

## 발굴 화면

| 요소 | 동작 |
|---|---|
| 배경 | 후면 카메라(`getUserMedia`, `facingMode: environment`). 권한 거부·카메라 없음·HTTPS 아님이면 흙바닥 그림과 안내 |
| 기울기 | `deviceorientation`의 beta. 휴대폰을 아래로 숙일수록(55° 이하면 전부) 흙더미가 화면 아래에서 올라옵니다. 똑바로 세우면 "아래로 기울이세요" 안내. 센서가 없는 PC면 처음부터 다 보임. iOS는 발굴하기를 누를 때 권한을 묻습니다 |
| 흙 | 흔함 2겹, 조금 드묾·희귀 3겹, 전설 4겹(마른 흙 → 진흙 → 자갈 → 붉은 점토). 깊을수록 단단합니다 |
| 완료 | 파편 그림이 덮는 칸의 70%가 바닥까지 드러나면 획득. 겹이 처음 뚫릴 때와 완료할 때 진동 |
| 나가기 | 중간에 나가면 진행은 버리고 지점은 그대로 남습니다 |

획득은 화면이 아니라 `GameState.dig`가 정합니다. 오늘 지점을 다시 계산하고 거리(20m)와 GPS 정확도(50m)를 다시 확인한 뒤에만 기록합니다.

## 게임 규칙

- 플레이 영역은 대한민국입니다(`src/core/korea.ts`). 영역 밖이면 지점이 없고 안내가 뜹니다.
- 약 150m 격자 칸마다 발굴 지점 0~2곳. 배치는 **한국 시간 자정**마다 바뀌고, 시드로 결정되어 같은 날 같은 장소면 늘 같습니다.
- 지도의 노란 원(반경 60m)은 실제 지점에서 0~35m 어긋난 곳을 중심으로 그립니다. 실제 지점은 항상 원 안에 있습니다.
- 한 번 판 지점은 그날 다시 나오지 않습니다.

| 도자기 | 희귀도 | 흙 겹 | 중복 시 고운 흙 | 교환 비용 | 복원 보너스 |
|---|---|---|---|---|---|
| 옹기 항아리, 분청사기 인화문 대접 | 흔함 | 2 | 1 | 5 | 3 |
| 백자 둥근 항아리, 청화백자 풀꽃무늬 병 | 조금 드묾 | 3 | 2 | 10 | 6 |
| 청자 상감 구름학무늬 매병 | 희귀 | 3 | 4 | 20 | 12 |
| 청자 연꽃 향로 | 전설 | 4 | 10 | 50 | 30 |

조정할 값:

| 값 | 위치 |
|---|---|
| 격자 크기, 칸당 지점 수, 탐색 원, 시드 | `src/game/sites.ts`의 `DEFAULT_SITE_CONFIG` |
| 탐지 거리 100m, 발굴 거리 20m, 정확도 한도 50m | `src/game/detector.ts`의 `DEFAULT_DETECTOR_CONFIG` |
| 겹별 단단함, 붓 크기, 완료 비율 | `src/game/excavation.ts`의 `excavationConfig` |
| 도자기 목록, 가중치, 흙 값 | `src/game/pottery.ts` |

## 도자기 그림

`art/raw/*.png`는 Codex(GPT 이미지 생성)로 만든 원본입니다. 실존 소장품을 베끼지 않은 오리지널 디자인이고, 마젠타 단색 배경으로 받았습니다.
`python scripts/make_pottery.py`(Pillow 필요)가 배경을 지우고, 4조각으로 깨진 모양을 잘라 `public/pottery/`에 저장합니다. 그림을 바꾸면 이 스크립트를 다시 실행하세요. 그림을 못 불러오면 게임은 도자기 색 도형으로 대신 그립니다.

## Android 앱(APK)

Capacitor로 감쌉니다. appId는 `com.potterydig.app`으로, 기존 게임(`com.gpscollect.app`)과 달라 한 폰에 둘 다 설치됩니다. 앱은 실제 GPS 모드로 시작하고, 아래쪽 🕹️ 버튼으로 시뮬레이터로 바꿀 수 있습니다. iOS는 Mac이 필요해 보류입니다.

준비(처음 한 번): JDK는 Android Studio에 든 것(`C:\Program Files\Android\Android Studio\jbr`), SDK 경로는 `android/local.properties`(git에 안 올라감)에 `sdk.dir=C:/Users/<사용자>/AppData/Local/Android/Sdk`. 카카오 사이트 도메인에 `https://localhost`(앱 WebView 주소)가 등록돼 있어야 앱에서 카카오 지도가 뜹니다.

웹을 빌드해 `android/`에 복사합니다. 웹 코드나 `.env.local`을 바꿀 때마다 다시 실행합니다.

```bash
npm run android:sync
```

디버그 APK 만들기 (PowerShell):

```powershell
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"; .\android\gradlew.bat -p android assembleDebug
```

결과물은 `android/app/build/outputs/apk/debug/app-debug.apk`입니다. USB 디버깅으로 `adb install -r <apk>` 하거나, 파일을 휴대폰에 옮겨 설치합니다(출처를 알 수 없는 앱 허용).

앱 권한: 정밀 위치(20m 발굴 판정에 필요), 카메라(발굴 화면, 처음 열 때 물음), 진동, 인터넷.

## 확인한 것 / 못 한 것 (2026-10-21)

확인함 (PC, 앱 내장 브라우저, 시뮬레이터):
- 카카오 스카이뷰 지도, 노란 탐색 원, 탐지기 신호가 거리에 따라 바뀜, 20m 안에서 발굴 버튼.
- 발굴 화면: 카메라가 막힌 환경에서 흙바닥 그림 대체와 안내, 마우스로 문질러 3겹을 차례로 걷어냄, 70%에서 파편 공개와 결과 카드.
- 도감에 조각 표시, 새로고침 후 조각·판 지점 기록 유지, 판 지점은 지도에서 사라짐.
- 휴대폰 폭(375px) 지도 화면 배치, 단위 테스트, `npm run build`.
- Android 에뮬레이터: 디버그 APK 설치·실행, 앱 안에서 카카오 위성 지도, 실제 GPS 모드에서 탐지기 패널 표시.

못 함 (실기기 필요):
- 실제 후면 카메라 영상(앱·HTTPS 모두), 기울기(자이로) 연출, 진동, 터치 문지르기 손맛, 실제 GPS로 걸어서 찾기.
- 앱 안에서 발굴 화면까지 들어가 보는 것(에뮬레이터에서는 지도 화면까지만 확인).
- 탐지기 소리는 코드만 있고 귀로 확인하지 않았습니다.
